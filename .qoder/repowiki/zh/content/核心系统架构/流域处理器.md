## 简介

中国SHUC流域处理器是整个中国流域分级统一编码系统的核心组件，负责实现智能流域合并算法。该系统采用创新的动态阈值自适应算法和拓扑保持的多目标优化合并框架，为中国的流域管理提供标准化、层次化的空间单元编码解决方案。

本系统的核心创新包括：
- **动态阈值自适应算法** — 采用 Q75 + (Q90-Q75)/2 公式智能计算合并阈值，自适应不同区域的流域特征
- **拓扑保持的多目标优化合并框架** — 在图约束优化下实现面积-形状-拓扑三方权衡，确保流域空间关系一致性
- **6级12位层级编码体系** — 完整覆盖从一级流域到子流域的精细分级，支持层级追溯与空间聚合

## 核心组件

### 流域处理器 (WatershedProcessor)

WatershedProcessor是系统的核心算法引擎，实现了智能流域合并的所有关键功能：

#### 主要功能特性
- **动态阈值计算** — 基于数据分布的自适应阈值计算
- **激进合并策略** — 高效的流域合并算法
- **拓扑关系维护** — 保持流域间的空间关系
- **合并历史追踪** — 记录合并过程和统计信息

#### 核心算法实现

```mermaid
flowchart TD
Start([开始合并流程]) --> LoadData[加载和预处理数据]
LoadData --> CalcThreshold[计算动态阈值]
CalcThreshold --> BuildGraph[构建拓扑图]
BuildGraph --> Loop{迭代循环}
Loop --> Identify[识别合并候选]
Identify --> MergeCandidates{有候选?}
MergeCandidates --> |是| MergeIteration[执行合并迭代]
MergeCandidates --> |否| CheckCompliance[检查合规率]
MergeIteration --> UpdateTopology[更新拓扑关系]
UpdateTopology --> CheckCompliance
CheckCompliance --> ComplianceRate{合规率达到目标?}
ComplianceRate --> |是| End([结束])
ComplianceRate --> |否| MoreIterations{还有迭代次数?}
MoreIterations --> |是| Loop
MoreIterations --> |否| End
UpdateTopology --> RemoveSource[删除源流域]
RemoveSource --> Loop
```

### 流域处理器深度分析

#### 动态阈值计算机制

动态阈值计算是系统的核心创新之一，采用统计学方法自适应不同区域的流域特征：

```mermaid
flowchart LR

F --> G

end
H --> J

```

**图表来源**
- [watershed_processor.py:117-141](file://01_CORE_SYSTEM/src/watershed_processor.py#L117-L141)

动态阈值计算公式：`threshold = max(50, min(100, Q75 + (Q90-Q75)/2))`

这个公式的优势在于：
- **自适应性强** — 能够根据数据分布自动调整阈值
- **稳定性好** — 通过约束范围避免极端值影响
- **鲁棒性高** — 使用分位数而非均值，减少异常值干扰

## 故障排除指南

### 常见问题及解决方案

#### 数据加载问题

- **原因**：文件损坏或编码问题
