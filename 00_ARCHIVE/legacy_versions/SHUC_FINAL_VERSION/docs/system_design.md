# 中国SHUC系统设计说明

## 1. 设计背景

### 1.1 项目目标
基于美国HUC (Hydrologic Unit Code) 系统，设计适合中国地理特征的流域分级编码系统，实现流域的标准化管理和编码。

### 1.2 参考标准
- **美国HUC系统**: 2-12位分级编码体系
- **USGS流域边界数据集**: 面积阈值和分级标准
- **国际水文编码规范**: 编码规则和质量标准

## 3. 分级体系设计

### 3.1 完整6级标准

| 级别 | 编码位数 | 面积范围(km²) | 描述 | 对应美国HUC |
|------|----------|---------------|------|-------------|
| 1级 | 2位 | ≥50,000 | 大区流域 | HUC-2 Region |
| 2级 | 4位 | 10,000-50,000 | 区域流域 | HUC-4 Subregion |
| 3级 | 6位 | 2,000-10,000 | 大流域 | HUC-6 Basin |
| 4级 | 8位 | 500-2,000 | 中流域 | HUC-8 Subbasin |
| 5级 | 10位 | 150-500 | 小流域 | HUC-10 Watershed |
| 6级 | 12位 | ≥100 | 基本单元 | HUC-12 Subwatershed |

### 3.2 编码规则

#### 3.2.1 层次化编码
- 每级增加2位数字
- 高级别编码包含低级别编码
- 示例：`010101010101` = 01(1级) + 01(2级) + 01(3级) + 01(4级) + 01(5级) + 01(6级)

#### 3.2.2 编码分配
- 同级别内按面积大小排序编码
- 01-99: 正常流域编码范围
- 保留特殊编码用于特殊情况

### 3.3 主要流域编码

```
01: 长江流域     02: 黄河流域     03: 珠江流域
04: 松花江流域   05: 淮河流域     06: 海河流域  
07: 辽河流域     08: 太湖流域     09: 东南沿海
10: 西南诸河     11: 西北内流区   12: 东北内流区
```
