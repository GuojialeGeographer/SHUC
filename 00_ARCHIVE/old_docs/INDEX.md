### 2. NATURE_WATER_FEASIBILITY_ANALYSIS.md

**核心内容**：
- Nature Water期刊概况（IF~15-20, 录用率<10%）
- China SHUC与Nature Water匹配度评估（3.2/5）
- 冲击Nature Water的机遇与挑战
- 如果决定冲击，需要的增强策略
- 与WRR/数据期刊的对比策略

**关键结论**：
```
直接冲击成功率：20-30%
推荐策略：先WRR/ESSD，后Nature Water
增强工作量：万级流域验证 + 应用案例
```

**适合阅读场景**：
- 评估是否要冲击顶刊
- 了解顶刊要求和差距
- 规划长期发表策略

```
- 匹配度：⭐⭐⭐⭐⭐
```

**适合阅读场景**：
- 规划数据论文投稿

### 4. ALGORITHM_PAPER_STRATEGY.md

**核心内容**：
- 算法论文 vs 数据论文的本质区别
- 适合算法/框架的期刊推荐
- 算法论文的核心内容框架（WRR标准）
- 两论文的配合策略（引用关系、时间配合）
- 三论文组合（数据+算法+应用）

**关键对比**：
```
数据论文 ≈ 产品说明书
算法论文 ≈ 技术专利
应用论文 ≈ 客户案例
```

**重点推荐**：
```
首选期刊：Water Resources Research (WRR)
- IF：~6.0
- 录用率：~30%
- 匹配度：⭐⭐⭐⭐⭐
- 核心卖点：动态阈值自适应算法
```

**适合阅读场景**：
- 规划算法论文投稿
- 理解数据论文和算法论文的配合
- 准备方法学创新发表

  - Phase 2: 数据论文撰写（Week 3-6）

  - Phase 4: 投稿与审稿（Week 11-20）

- 检查清单与里程碑

**关键时间线**：
```
Month 1: 数据准备 + 数据论文撰写
Month 2: 数据论文投稿 + 算法实验
Month 3: 数据论文审稿 + 算法论文撰写

Month 5: 算法论文审稿
Month 6-7: 算法论文接收

总时间：6-7个月
预期产出：2篇论文（ESSD + WRR）
```

**适合阅读场景**：
- 开始执行发表计划
