## 🎯 部署与使用指南

### 快速开始
```bash
# 1. 环境准备
pip install geopandas pandas networkx shapely numpy scipy matplotlib

# 2. 运行优化版SHUC系统  
python shuc_system_optimized.py

# 3. 查看结果
ls output_optimized/
# 预期输出: optimized_shuc_watersheds.shp (90%合规)

# 4. 运行DEM边界处理器
python seamless_dem_processor.py  

# 5. 查看DEM处理结果
ls seamless_output/
# 预期输出: 252个瓦片，911个重叠区域分析
```

### 系统配置选项
```python
# shuc_system_optimized.py 配置
config = {
    "dynamic_threshold": "auto",     # 自动计算或手动设置
    "merge_strategy": "aggressive",  # 激进合并策略
    "max_iterations": 50,           # 最大迭代轮次
    "target_compliance": 0.80,      # 目标合规率80%
    "level_quotas": {4: 3, 5: 8}   # 层次分配配额
}

# seamless_dem_processor.py 配置  
dem_config = {
    "processing_buffer": 50000,     # 50km处理缓冲区
    "quality_thresholds": {
        "elevation_discontinuity": 50,
        "flow_direction_error": 0.1
    }
}
```

### 结果解读
